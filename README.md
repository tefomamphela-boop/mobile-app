# ReCircle — Recycling made rewarding

ReCircle is a mobile-friendly app concept designed to make recycling easier and more motivating for people in local communities. It brings sample recycling options together, lets users log materials, and shows points and estimated material diverted.

## The problem
People may want to recycle but struggle to find reliable information about nearby drop-off points, what materials are accepted, and whether their small actions make a difference. Information can be scattered across notices, social media posts, or different service providers.

## The solution
ReCircle combines:
- A directory of community recycling options.
- A quick recycling log for plastic bottles, cans, paper, and glass.
- A points system to encourage participation.
- A simple impact dashboard.
- A future partner model for schools, community groups, recyclers, and local businesses.

## Target users
- Households and students who want convenient recycling information.
- Community groups and schools running clean-up or collection drives.
- Recycling businesses and local sponsors seeking community participation.

## Run the prototype
No installation is required:
1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Try **Log recycling +**, choose a material and quantity, and add it to your demo impact.
4. Use the location cards to see the sample location details.

The app is built with plain HTML, CSS, and JavaScript, so it can be hosted on GitHub Pages.

## Files
- `index.html` — app layout and content.
- `styles.css` — responsive visual design.
- `app.js` — demo interactions, points, and impact tracking.
- `pitch.md` — two-minute investor pitch and presenter notes.
- `presentation.pptx` — project presentation.

## GitHub Pages deployment
1. Create a new GitHub repository, for example `recircle-app`.
2. Upload all project files to the repository's root.
3. Open **Settings → Pages**.
4. Under build and deployment, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site and open the provided URL.

## Business model
A possible future model is free for community members, with optional paid partner dashboards for organisations that run collection campaigns, sponsored community challenges, and clearly labelled local business rewards. Revenue ideas need testing with partners before launch.

## What makes it different?
Rather than being only a list of recycling locations, ReCircle combines discovery, action logging, personal progress, and community participation in one simple experience. The demo locations are fictional and clearly labelled as examples.

## Design thinking
1. **Empathise:** People may have good intentions but lack clear local information and motivation.
2. **Define:** How might we make it easier for community members to find recycling options and feel their effort matters?
3. **Ideate:** Combine location discovery, simple logging, points, and visible progress.
4. **Prototype:** Build a responsive web prototype with working item logging and sample location cards.
5. **Test:** Ask users whether locations are understandable, which rewards motivate them, and whether they would log recycling consistently.

## Limitations and next steps
- Locations, distances, schedules, points, and environmental weights are illustrative demo data, not live or verified.
- A real launch would require verified partners, map/location services, user accounts, privacy controls, fraud prevention, and testing of reward economics.
- Environmental impact estimates should be reviewed with qualified recycling partners before being presented as verified measurements.

## Accessibility and privacy
The prototype uses responsive layouts, native form controls, readable contrast, and dialog labels. It does not collect or send personal data; interactions run locally in the browser.
